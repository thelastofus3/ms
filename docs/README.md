# Цифровая комната

Проект гибридной встречи в цифровой копии реального помещения.

**Состояние:** реализован прототип Avatar Service: Blender/MPFB, GLB-пакеты, очередь PostgreSQL, API и React-просмотр с управлением. [Запуск](../README.md). Генерация комнаты, реальный трекинг и конференция ещё не реализованы; показатели общего проекта остаются критериями будущей приёмки.

Каждая подсистема получает собственный план реализации после проверки спецификаций. Общие координаты, идентификаторы и правила публикации ресурсов определяются общим дизайном; локальные детали — соответствующей спецификацией.

## Будущая структура исходного кода

```text
apps/web/                  React: встреча, редактор пространства, режим телевизора
services/platform/         Java: пользователи, встречи, каталог, синхронизация
services/space/            Python: задания реконструкции пространства
services/avatar/           Python/Blender: задания сборки аватаров
agents/tracking/           Python: захват камеры, калибровка, поза, идентификация
contracts/                 OpenAPI, JSON Schema, примеры совместимых сообщений
infra/                     локальный запуск и конфигурация сервисов
docs/                      спецификации, решения, схемы, планы, отчёты проверок
```

Это описание целевой структуры. Пустые каркасы сервисов не создавались.
